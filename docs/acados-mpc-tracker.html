AcadosMpcTracker：作用与处理流程

端侧空间跟踪器：用滞后估计的 q̂ 追 PlanBuffer 参考，在 100 Hz 环上解短时域臂 MPC； 超时或失败则降级到已验证的 LeadTracker，保证热路径不断命令。 实现：tracker/acados_mpc.py + tracker/arm_mpc_acados.py（移植 V2 AcadosPlanner 的 SQP-RTI OCP）。

契约：design §5.2 · deploy-g2-plan §4.5 · tests/deploy/test_acados_mpc_tracker.py · extra：fastervla[mpc] + 系统 acados

为什么需要

已有 LeadTracker

F2 soft lead 基线

开环：u ≈ r + clip(gain · (·))。 1.0× 够用；κ 升高后难显式守住 Δy / 加速度盒。

F4 AcadosMpcTracker

闭环约束跟踪

从 q̂ 出发短时域优化，硬约束增量与速率； 求解不可靠时退回 Lead，不堵控制环。

TimeAxisQP（L2）只改时间轴、不改路径； MPC（L3）在关节空间上把「参考 → 可执行命令」压进物理盒。 二者分工：κ / QP 决定「路点何时到」，MPC 决定「这一拍命令往哪拧」。

在栈中的位置

InferenceLoop / ControlLoop @ 100 Hz PlanBuffer.reference(...) → reference r (21) LagStateEstimator.estimate() → q̂ (14 臂) │ ▼ AcadosMpcTracker.step(q̂, r, ref_ahead, ref_vel, now) │ 成功 │ 失败 / 超时 / 无 acados ▼ ▼ 臂命令 [5:19] ← MPC LeadTracker.step(...) （fallback_count++） │ │ └──────────┬──────────────┘ ▼ 夹爪 [19:21] 始终透传自 reference ▼ CommandSink.send(y_21)

输入 / 输出

q_hat形状 (14,)。滞后回放得到的当前臂估计，不是原始测量。
reference形状 (21,)。命令布局：腰/臂/夹爪；MPC 只动臂 [5:19]。
ref_ahead / ref_vel降级到 Lead 时需要；成功 MPC 路径可忽略或用于暖启动。
now单调时钟，供 lead EMA / 超时计量。
返回值形状 (21,)。臂来自 MPC 或 Lead；夹爪 = reference[19:21]。
可观测状态last_status、last_solve_ms、fallback_count、has_acados。
夹爪不进 MPC（与 design 一致）：按 lookahead 取参考即可，避免 14 维求解掺进开合自由度。

处理流程

  1. 校验：维数不对直接抛错（测试锁形状契约）。
  2. 后端探测：无 acados 且无注入求解器 → 立刻 Lead。
  3. 组问题：状态 x₀ = q̂，参考为当前臂目标（可带短 horizon）。
  4. 限时求解：墙钟 > solve_budget_ms（默认 8）视为 timeout。
  5. Δy 裁剪：成功解相对上一拍再夹一道，防单步跳变。
  6. 拼命令：只写臂；夹爪透传。
  7. 降级：任何失败路径调用内嵌 LeadTracker，计数可观测。

MPC 问题轮廓（已接线）

与 realtime-vla-v2 AcadosPlanner 同构，见 arm_mpc_acados.build_acados_ocp_solver：

状态 x = [q; y_prev; y_prev2] ∈ ℝ^{3·14} 控制 u = y_cmd ∈ ℝ^{14} 离散动力学（一阶滞后）： q⁺ = a·q + (1−a)·y_cmd , a = exp(−dt/τ) 代价 NONLINEAR_LS：跟踪 (q−r)、Δy、Δ²y 等（权重可配） 约束 h： |y − q| ≤ τ·v_max # soft-lead 式速率盒 |y − y⁻| ≤ dy_max |y − 2y⁻ + y⁻⁻| ≤ ddy_max y ∈ [q_min, q_max] 求解：nlp_solver_type = SQP_RTI，qp = PARTIAL_CONDENSING_HPIPM 单拍预算 < 8 ms；status≠0 或超时 → Lead

安装：pip install 'fastervla[mpc]'（casadi + acados_template）， 并按 acados 文档编译本机库、设置 ACADOS_SOURCE_DIR。 首次 eager_build=True 会导出 C 代码到临时目录并编译。 决策变量是空间命令，不是时间轴上的 s=1/dt。

降级策略

触发last_status（约定）
未安装 / 不可用no_acados

测试强制forced（force_fallback=True）
成功ok；fallback_count 不增加

验收（分期退出条件）：1.4× 下跟踪 p95 优于纯 Lead；求解超时率 < 1%。 G2 工控机是否装得动 acados，是 F4 前置实测项——装不动则长期走 Lead，模块仍须可构造、可降级。

关键配置

horizon_n默认 15
arm_dim14（双臂）
dt_s0.01
solve_budget_ms8.0
dy_max_rad单拍臂增量上限（测试默认 0.05）
ddy_max_rad二阶平滑盒（测试默认 0.5）
fallback目前仅 "lead"
一句话：AcadosMpcTracker = 「100 Hz 上对 14 维臂做限时约束跟踪；不行就 Lead」。 它不负责推理、不负责重定时、不负责夹爪；只把 q̂ 与参考收成可下发的 21 维命令。
