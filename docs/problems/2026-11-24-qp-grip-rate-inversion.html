旧 QP 夹放不稳：细动作被加速、搬运被减速

κ↑ 后用裸 TimeAxisQP，体感毛糙、夹球/放筒不准；uniform 同 κ 反而更稳。 根因是 QP 把时间分配反了，再叠加合块时时间轴重解导致速率跳变。 修法：夹爪窗硬限速 + 合块锁定旧计划时长。

1. 问题现象

  • κ=1.1 裸 QP·8+8（087e27）：体感尚可，3 球 2+1 次；但相对 uniform，交接跳更高。
  • κ=1.2 裸 QP·8+8（d84c6f）：毛糙；1 球成功、1 球入桶失败后掉桶。交接跳 687、hf3↑、rem↓。
  • 同 κ uniform 4+4（2018b7）：约 8 球较准较快，偶发放偏——说明「加速本身」还能用，问题在 QP 怎么分时间。
  • 主观感受：夹/放附近「冲」，空中搬运反而没明显提速；合块多（4+4）时更差。

2. 分析过程与原因

2.1 线上 step_dt 诊断

2.2 原因动画：加速度项在拉平关节速度

路点固定，相邻位移 dp 固定。QP 只改速率 s=1/dt。 加速度项最小化 ‖sᵢ·dpᵢ − sᵢ₊₁·dpᵢ₊₁‖²，等价于让相邻段关节速度尽量相等。 平均还要对齐 κ，又无 v_max → 只能「小步加速、大步减速」。

2.3 第二原因：合块时时间轴整段重解

InferenceLoop._retime_chunk 原先 lock_durations=None（注释写着 F3 follow-up）。 每个新 chunk 对同一批未来路点重新分配时长 → 交接处新旧速率差 p50≈10%、p95≈40%。 4+4 合块更勤，所以裸 QP·4+4 最差（交接跳 921）。

3. 解决方法

  1. 分段硬上限（进 QP 的 upper[]）： 先判定接触窗，再压速率上界——不是改目标函数。
  2. 合块时长锁定： qp_prefix_lock 时，旧计划 step_dt[anchor:anchor+d̂+extra] → lock_durations，前缀 lower=upper=1/dt。
  3. 配方： h7_k1p3_qp_phase_4x4.yaml （contact_kappa: 1.1 · contact_window_frames: 10 · transport_kappa_max: 1.5 · prefix_lock: true）。

3.1 对照代码：接触限制怎么加进 QP

文件 src/fastervla/deploy/postprocess/retime.py。 决策变量仍是每帧速率 s=1/dt；限制全部落在盒约束 lower[i] ≤ s[i] ≤ upper[i]。

① 配置（配方 → CLI → TimeAxisQPConfig）

retimer:
  type: qp
  contact_kappa: 1.1          # 接触窗内 s ≤ 30×1.1 = 33
  contact_window_frames: 10   # |Δgrip| 事件前后各扩 10 帧
  transport_kappa_max: 1.5    # 全帧 s ≤ 30×1.5 = 45
  prefix_lock: true

代码默认还约定：contact_grip_dims=(22,23)、 contact_grip_delta=0.02（即图上的 |Δgrip|>0.02）。 全局宽盒仍在：dt∈[dt_min_s, dt_max_s]=[0.015,0.08] → s∈[12.5, 66.7]。接触/搬运上限是在这之上再 min。

② 判定接触窗：contact_mask()

g = actions[:, grip_dims]           # 默认维 22/23，夹爪命令不是实测
step = max_|Δg| across dims         # 相邻帧差
events = where(step > delta) + 1    # delta=0.02
mask[e-window : e+window+1] = True  # window=10 → 图上「±10」

输出是长度为 H 的 bool 掩码。这一步只回答「哪些帧算接触」， 还没有限速；图上 |Δgrip|>0.02 ±10 指的就是它。

③ 写入 upper[]（真正的限制）· _retime_qp

lower[:] = 1/dt_max;  upper[:] = 1/dt_min          # 全局盒
upper = min(upper, v_max/|dp|)                     # 可选关节速度
upper = min(upper, policy_fps * transport_kappa_max)  # 全帧 ≤1.5×
near  = contact_mask(...)
upper[near] = min(upper[near], policy_fps * contact_kappa)  # 窗内 ≤1.1×
# 然后 box_qp / calibrate：在 [lower, upper] 内求 s，平均仍对齐 κ

κ=1.3 配方下数值：接触窗 s≤33（不能再冲到 1.4–1.5×）， 其它帧 s≤45，全局仍受 s≤66.7 约束（通常 transport 先顶到 45）。 校准用的 calib_upper 不含接触盖帽， 这样平均对齐 κ 时，会把省下的时间推到未盖帽的搬运帧。

不是改 rate_hessian 目标函数；加速度项还在。 只是接触帧的可行域被盒子截断，解再也走不到「细动作狂加速」。

④ 合块锁定（另一路约束）· inference_loop

lock = old_step_dt[anchor : anchor + d_hat + qp_lock_extra]
# qp_prefix_lock 时传入 TimeAxisQP.retime(..., lock_durations=lock)
lower[:locked] = upper[:locked] = 1/lock_dt   # 前缀钉死，不能重解

修法动画：掩码 → upper 盖帽 → 时间挪去搬运

接触窗帧（s≤1.1×） 搬运（s≤1.5×） contact_mask

点「播放」：先画 mask（|Δgrip|±10）→ 再把窗内 s 压到 ≤1.1× → 搬运抬高。
