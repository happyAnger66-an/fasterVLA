  • 时间分配反了：加速度项 \(\|s_i dp_i - s_{i+1} dp_{i+1}\|^2\) 拉平关节速度，且无 v_max → 小步/夹爪附近被加速（κ=1.2 时夹爪段 1.28–1.33×、小步 1.47–1.54×），搬运大步反而 1.04–1.12×。uniform 1.2 夹爪段只有 1.2×，所以更准。

5. 控制跟随质量（时滞 / 误差分解 / 频响）

脚本：scripts/analyze_control_quality.py（同 fastervla-deploy analyze 的 control 块）· 数据 results/control_quality_20261124.json · 口径：stage=step，单臂 7 关节 L2，左右臂运动时合并；分档按命令关节速度 max|v| (rad/s)，<0.2 rad/s 时滞无定义不计。表头 ↓ 越小越好 / ↑ 越大越好；单元格 绿=该列最优、橙=该列最差（并列都标）。

  • 本体固有时滞 ≈ 90 ms，与加速无关：命令→实测路径时滞 p50 88–91 ms（69b2b6 为 84；p95 105–128），15 场、κ 1.0→1.3、uniform/QP 全部一致。速度互相关 ≈ 94–102 ms；1 Hz 相位延迟 75–108 ms、3 Hz 96–108 ms——三种方法互证。相位延迟随频率略增（一阶滞后应随频率减小），更像「纯延时 + 高阶伺服」，与 Lead 的一阶 τ=57 ms 假设不符。
  • Lead 只补回 ≈20 ms：对参考的净时滞 p50 ≈ 70 ms（p95 ≈ 100）。高速档净时滞更大（0.2–0.5 档 ≈ 66 → ≥2 档 ≈ 78 ms），与 lead 限幅 0.06 rad 在高速被顶住一致。
  • 不是带宽 / 限速问题：−3 dB 带宽 3.9–4.7 Hz，而命令 95% 能量在 1.2 Hz 内（377a77 为 1.6）；各速度档速度增益 0.93–1.01，≥2 rad/s 也不掉速 → 幅度跟得上，只是晚到。
  • 误差主要是「慢」不是「偏」：关节总误差 p95 205–376 mrad，扣掉最佳时移后残差只剩 54–85，路径轮廓 p95 24–70。末端：轮廓 p95 4.6–8.3 mm，含时滞的总误差 p95 28–46 mm。
  • 加速的代价 = 同样 90 ms × 更高速度：见下表 κ 组均值；EE 总误差 p95 随 κ 单调变差。
  • 阶段差（§5.3b）：grasp 窗 EE 误差最小；κ↑ 的高速代价主要在 seek / carry（尤其 fast 子集）。
  • 夹取瞬间手基本到位：右爪闭合时刻 EE 偏参考 p50 2.5–6.0 mm、max ≤ 12.3 mm。单靠闭环跟随解释不了「离球远多次夹」，需逐球标注对照（更可能在策略 / 视觉侧）。
